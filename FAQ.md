# Frequently Asked Questions (FAQ)

### What is the primary purpose of Voice Cooking Assistant & Kitchen AI?
Hands-free voice-activated culinary assistant and step-by-step recipe companion powered by speech synthesis.

### What technology stack is utilized?
React / TypeScript, Web Speech API, Node.js.

### How do I run this locally?
Clone the repository and serve the assets using a static HTTP server or run the development script according to `package.json`.
